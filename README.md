# MultiStepForm FEM 

## Description:
 This project is a challenge from frontendmentor.io 
 The challenge was to create a four-step form (wizard form) to capture and save the information provided by the user.
 Furthermore, the provided example style had to be followed.
 ---
## Features:
- It has a pseudo navigation, with 4 steps
- Sends the information given by the user to the console
- Responsive design
---
## Stack
- Angular 21
- Tailwindcss 4.1
